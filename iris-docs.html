Generické typy

class Box<T> {
    var item: T
    fun get(): T { return item }
}
NaN-boxing: Všechny hodnoty jsou 8 B (Value). Int, bool, null a SSO string se ukládají přímo do value. Double, heap string, object, array a native pointer se ukládají jako pointer se speciální NaN-signaturou.

Řídicí struktury

Podmínky (if/else)

if (x > 0) {
    print("kladné")
} else if (x < 0) {
    print("záporné")
} else {
    print("nula")
}

Cykly

// while
while (x < 10) {
    x = x + 1
}

// for (C-style)
for (var i = 0; i < n; i = i + 1) {
    print(i)
}

// repeat (pevný počet)
repeat (5) {
    print("Ahoj")
}

// break / continue
while (true) {
    if (done) break
    if (skip) continue
}

Switch

switch (x) {
    case 1 { print("jedna") }
    case 2 { print("dva"); break }
    default { print("jinak") }
}

Switch lze použít i jako výraz (vrací hodnotu z case/default).

Funkce

Deklarace

fun add(a: int, b: int): int {
    return a + b
}

// bez návratového typu (vrací null)
fun greet(name: string) {
    print("Ahoj " + name)
}

// tail-call optimalizace
fun fact(n: int, acc: int): int {
    if (n <= 1) return acc
    return fact(n - 1, acc * n)  // tail call
}

Volání

add(3, 4)
obj.method()
ClassName.staticMethod()

Třídy & OOP

Základní třída

class Person {
    var name: string
    var age: int

    Person(name: string, age: int) {
        this.name = name
        this.age = age
    }

    fun greet() {
        print("Jsem " + this.name)
    }
}

Dědičnost

class Student : Person {
    var school: string

    Student(name: string, age: int, school: string) {
        super.Person(name, age)
        this.school = school
    }

    override fun greet() {
        super.greet()
        print(" — student na " + school)
    }
}

Řetězce

Základní operace

val s = "Hello" + " " + "World"  // konkatenace (rope-based, O(1))

Bytecode VM & JIT

Virtuální stroj

  • Register-based VM s 256 registry na frame
  • NaN-boxed hodnoty (vše 8 B Value)
  • 105 definovaných opcode
  • Flat call stack s register windowing
  • Garbage collector: mark-and-sweep (trigger po 256 operacích v cyklech)
  • Peephole optimalizace bytecodu

JIT kompilace

  • Trace-based JIT přes Asmjit knihovnu
  • Detekce hot loopů a jejich kompilace do nativního x86-64 kódu
  • Method stuby kompilované po prvním zavolání
  • Polymorphic inline cache pro dynamický method dispatch
  • SIMD optimalizace (arraySum)
